讲义变卡组，
一个粘贴的距离。

粘贴一段教材或讲义，本地规则引擎立刻抽出问答卡。全程在你的浏览器里完成——文本不经过任何服务器，出什么卡一目了然。

1粘贴材料，或加载学科示例
2生成并导出
导入 Anki / AnkiDroid：下载 TSV → Anki 菜单「文件 → 导入」→ 字段分隔符 Tab → 导入。
想要精美 .apkg 单文件（渐变描边模板 / 深色模式 / 来源标签）？用 PC 版：anki-forge import 材料.md --deck 卡组名，或图形界面 anki-forge ui。
安卓主屏安装：浏览器菜单 →「添加到主屏幕」，本页即成为独立离线应用。
anki-forge 开源（MIT）· GitHub 仓库 · 下载 PC 版（内嵌完整图形界面）
体验版仅支持纯文本；PDF / PPT / Word / Excel 请用 PC 版。结果仅供试用，导入与否由你决定。

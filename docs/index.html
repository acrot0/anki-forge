网页体验版 · 全程本地运行 · 无需注册

讲义变卡组，
一个粘贴的距离。

粘贴一段教材或讲义，本地规则引擎立刻抽出问答卡。文本不离开你的浏览器——无账号、无 API Key、无上传。

1粘贴材料
2生成并导出
导入 Anki / AnkiDroid：下载 TSV → Anki 菜单「文件 → 导入」→ 选该文件 → 字段分隔符 Tab → 导入。
想要更漂亮的 .apkg 单文件（含深色模板、来源标签）？用 PC 版：anki-forge import 材料.md --deck 卡组名，或图形界面 anki-forge ui。
安卓主屏安装：浏览器菜单 →「添加到主屏幕」，本页即成为独立应用（离线可用）。
anki-forge 开源（MIT）· GitHub 仓库 · 下载 PC 版（exe 内嵌完整图形界面）
体验版仅支持纯文本；PDF / PPT / Word / Excel 请用 PC 版。生成结果仅供试用，导入与否由你决定。
